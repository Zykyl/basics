# papers

논문화 작업을 위한 폴더입니다.

- `research/`가 외부 자료 수집, `notes/`가 정리되지 않은 생각이라면, `papers/`는 실제로 작성 중이거나 완성된 논문 원고를 담는 곳입니다.
- 논문(또는 투고 대상)별로 하위 폴더를 만드는 것을 권장합니다.
  - 예: `papers/<paper-name>/draft.md` (또는 `.tex`)
  - `papers/<paper-name>/figures/` — 그림, 그래프
  - `papers/<paper-name>/data/` — 실험/분석 데이터
  - `papers/<paper-name>/references.bib` — 참고문헌
- 투고 상태(초안/리뷰중/게재)를 각 논문 폴더의 README에 기록해두면 관리하기 편합니다.
