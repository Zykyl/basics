# basics

기본적인 개발을 위한 자료를 수집하고 정리하는 저장소입니다.

## 폴더 구조

| 폴더 | 용도 |
|---|---|
| [`research/`](research/README.md) | 연구에 필요한 자료 수집 (논문, 아티클, 레퍼런스 문서, 스크랩) |
| [`sources/`](sources/README.md) | 개발 소스 코드 저장 (프로젝트, 예제 코드, 실험 코드) |
| [`scripts/`](scripts/README.md) | 필요할 때마다 작성하는 도구/유틸리티 스크립트 |
| [`notes/`](notes/README.md) | 연구 노트, 학습 기록, 진행 일지 |

각 폴더의 세부 사용법과 정리 기준은 폴더별 README를 참고하세요.
